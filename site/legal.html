Privacy

This section explains which personal data are processed when you visit this website, as required by the EU General Data Protection Regulation (GDPR).

Who is responsible

The controller is Stefan Decker, at the address given in the Impressum.

What this website does not do

The website sets no cookies, uses no analytics or tracking, has no forms, and loads nothing from other servers: no web fonts, scripts or embedded videos. Your browser stores nothing for it. The copy button on the home page only puts text into your own clipboard.

Hosting on GitHub Pages

The website is hosted on GitHub Pages, a service of GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. When you open a page, your browser sends GitHub's servers the data that every web request contains: your IP address, the page requested, the date and time, and usually your browser type and the page you came from. GitHub needs these data to deliver the page. According to GitHub's documentation, it logs the IP address of every visitor to a GitHub Pages site for security purposes. GitHub does not make these logs available to me.

The legal basis is Art. 6 (1) (f) GDPR: the legitimate interest in delivering this website reliably and securely. GitHub processes the data in the USA. GitHub, Inc. states that it complies with the EU–U.S. Data Privacy Framework, for which the European Commission has adopted an adequacy decision (Art. 45 GDPR). GitHub does not publish a fixed retention period for these logs; details are in the GitHub General Privacy Statement.

Links to other websites

This website links to GitHub, for the source code and documentation, and to YouTube, for the demonstration video. Nothing is loaded from these services until you follow such a link. Their own privacy policies then apply.

Email

If you write to me by email, I use your address and your message only to answer you (Art. 6 (1) (f) GDPR) and delete them when the conversation has ended.

Your rights

You have the right to access your personal data (Art. 15 GDPR), to have them corrected (Art. 16) or erased (Art. 17), to restrict their processing (Art. 18), and to object to processing based on legitimate interests (Art. 21). As I have no access to GitHub's server logs, requests about those logs are best sent to GitHub as well, using the contacts in its privacy statement. You also have the right to lodge a complaint with a data protection supervisory authority (Art. 77 GDPR), in particular in the EU member state where you live or work.
