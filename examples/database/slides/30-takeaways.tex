\begin{frame}[t]{One question, several ways to investigate}
\begin{itemize}
\item \textbf{SQL:} filter, join, count, find absence and preserve duplicates.
\item \textbf{SPARQL:} return bindings, a boolean or a constructed graph.
\item \textbf{Turtle:} write RDF facts with stable resource identifiers.
\item \textbf{Shared graphs and quizzes:} compare models and explain reasoning.
\end{itemize}\vspace{4mm}
Matching one reference result is evidence about \emph{this dataset}.\par
It is not a proof of agreement on every possible database.
\note{Ask for a new data row that distinguishes a plausible wrong query: a member with only returned loans, or a second Ada. README.md maps activities to their source and explains the next extension.}
\end{frame}
